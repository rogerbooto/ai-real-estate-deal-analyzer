# Core AI & Agents
# Ceiling is deliberate and evidence-based, not caution. `crewai>=0.28.0` (no ceiling) let CI
# install 1.15.11 against a developer machine on 0.193.2 -- a 0.x -> 1.x MAJOR jump. 1.x
# validates OPENAI_API_KEY when an Agent is CONSTRUCTED rather than when it is called, so simply
# instantiating a deterministic agent began requiring a key and CI went red on tests whose whole
# premise is that no model is involved. Raise this ceiling only with a run of the suite against
# the new major, since that is the boundary the break crossed.
crewai>=0.28.0,<1.0.0
