# schemas

## Purpose / Responsibilities

* Single source of truth for **data models and validation** across the AI Real Estate Deal Analyzer.
* Defines typed contracts for all agents, orchestrators, and core modules using **Pydantic v2** models.
* Ensures deterministic serialization/deserialization of inputs, listings, media artifacts, forecasts, and reports.
* Enables safe interchange between deterministic and AI-seamed components.

### Finance Models

| Model | Description |
| --- | --- |
| **FinancialInputs** | Root object containing financing, opex, income, refi plan, and market assumptions. Main input for `core/finance/engine.py`. Includes `income_is_estimated` and `capex_reserve_upfront`. |
| **FinancingTerms** | Loan assumptions: `purchase_price`, `closing_costs`, `down_payment_rate`, `interest_rate`, `amort_years`, `io_years`, `mortgage_insurance_rate`. All rates in **fractions [0–1]**. |
| **OperatingExpenses** | Yearly recurring costs: `insurance`, `taxes`, `utilities`, `water_sewer`, `property_management`, `repairs_maintenance`, `trash`, `landscaping`, `snow_removal`, `hoa_fees`, `reserves`, `other`, plus `expense_growth`. All non-negative. |
| **IncomeModel** | **Per-unit** revenue model: `units: list[UnitIncome]` (monthly `rent_month` + `other_income_month`), `occupancy`, `bad_debt_factor`, `rent_growth`. Unit count = `len(units)`. |
| **RefinancePlan** | Refi assumptions: `do_refi`, `year_to_refi` (refi at END of that year), `refi_ltv`, optional `exit_cap_rate`. |
| **MarketAssumptions** | Cap-rate context: `cap_rate_purchase`, `cap_rate_floor`, `cap_rate_spread_target`. |
| **FinancialForecast** | Engine output: `years: list[YearBreakdown]`, `purchase: PurchaseMetrics`, optional `refi: RefiEvent`, returns, warnings. |
| **YearBreakdown** | Single-year snapshot: GSI, GOI, per-line OPEX + `total_opex`, NOI, `debt_service`/`principal_paid`/`interest_paid`, `cash_flow`, `dscr`, `ending_balance`, valuation fields `cap_rate_applied`/`est_value`/`ltv_pct`/`available_equity`, and `notes`. **Not** annotations for IO years or the refi year — `engine.py:212-215` writes `notes` only from `_apply_insight_modifiers`'s `insight_notes`, and only at `y == 1`; a forecast with `financing.io_years` set and a realized later-year refi has empty `notes` in every year (verified). See `core/reports/README.md`'s "Adjustments Applied" section for what actually populates `notes`, and its honesty caveat on reachability. |
| **PurchaseMetrics** | Acquisition economics: cap rate, cash-on-cash return, DSCR, debt service, acquisition cash, spread. |
| **RefiEvent** | Realized refinance event inside a forecast (year, valuation, new loan, cash-out). |
| **InvestmentThesis** | Verdict + rationale + improvement levers. Generated by `agents/chief_strategist.py`. |

### Listing, Media & Ingest Models

| Model | Description |
| --- | --- |
| **ListingInsights** | Address, inferred `title`, stated facts (`price`, `sqft`, `bedrooms`, `bathrooms`, `year_built` — all optional, `None` = not stated/parsed), amenities, condition tags, defects, notes — the analyst output consumed by the finance engine and rendered as the report's "As listed" line. |
| **ListingNormalized** | Structured listing extraction (beds/baths/sqft/units/address/amenities) from text or HTML. |
| **AddressResult** | Parsed US/CA address (street, city, region, postal, country hint). |
| **PhotoInsights** / **DetectedLabelModel** / **ParkingSummary** | Per-image CV records and closed-set detections with rollups (rooms, amenities, defects, parking). |
| **FetchPolicy** / **HtmlSnapshot** | Network opt-in policy (robots, timeouts, cache, JS render) and cached fetch results. |
| **MediaCandidate / MediaAsset / MediaBundle / MediaFinderResult** | Media discovery → download → manifest pipeline types (sha256, dimensions, kinds). |
| **MediaInsights** | Media stats: counts, bytes, dimensions, orientation, duplicates (exact + perceptual), hero image. |
| **IngestResult** | End-to-end ingestion artifact: normalized listing + media bundle + photo insights + provenance. |

### Market Models (V2 — not yet wired into the main pipeline)

| Model | Description |
| --- | --- |
| **MarketSnapshot** | Baseline market state: `region`, `cap_rate`, `vacancy_rate`, `rent_growth`, `expense_growth`, `interest_rate`. All as **fractions**. |
| **MarketHypothesis** | Delta adjustments (absolute percentage points) applied to snapshot fields; includes rationale and prior weight. |
| **HypothesisSet** | Collection of `MarketHypothesis` with metadata, prior normalization, and determinism guarantees. |
| **RegionalIncomeTable** | Deterministic summary of income distributions for regional comps (p25/median/p75, turnover, STR uplift flag). |

### Label Ontology (`labels.py`)

Closed-set enums (`RoomType`, `MaterialTag`, `AmenityLabel`, `DefectLabel`, `ConditionTag`, `ParkingType`) plus deterministic normalizers from filenames/text and listing-field extractors (`extract_listing_common`, `detect_heating`, `detect_cooling`, amenity/defect text normalizers).

## Usage Examples

### Example 1 — Construct Financial Inputs (per-unit income)

```python
from src.schemas.models import (
    FinancialInputs, FinancingTerms, OperatingExpenses, IncomeModel, UnitIncome,
)

inputs = FinancialInputs(
    financing=FinancingTerms(
        purchase_price=500_000, closing_costs=10_000, down_payment_rate=0.25,
        interest_rate=0.055, amort_years=30, io_years=0,
    ),
    opex=OperatingExpenses(insurance=2400, taxes=6000, repairs_maintenance=2400,
                           property_management=4800),
    income=IncomeModel(
        units=[UnitIncome(rent_month=1200, other_income_month=50),
               UnitIncome(rent_month=1200)],
        occupancy=0.95, bad_debt_factor=0.97, rent_growth=0.03,
    ),
)
print(inputs.model_dump_json(indent=2))
```

### Example 2 — Market Snapshot + Hypothesis Set

```python
from src.market.snapshot import build_snapshot
from src.market.hypotheses import generate_hypotheses

snap = build_snapshot({"market": {
    "region": "Metro A", "cap_rate": 0.055, "vacancy_rate": 0.06,
    "rent_growth": 0.03, "expense_growth": 0.02, "interest_rate": 0.045,
}})
hs = generate_hypotheses(snap, seed=42)
print(hs.summary())
```

## Design Notes / Invariants

* **Rates and percentages**: always expressed as fractions (e.g., `0.05` = 5%); hypothesis deltas are absolute percentage points.
* **Currency**: all monetary fields in consistent nominal currency; no inflation adjustments.
* **Validation rules**: enforced via Pydantic validators (non-negative money, bounded fractions, closed-set enums).
* **Serialization**: deterministic order via field definitions; stable across runs.
* **Backward compatibility**: legacy `FinancialInputs`-root JSON is auto-translated to the structured shape by `src/inputs/inputs.py`.

## Dependencies / Optional Providers

* No runtime dependencies beyond **Pydantic v2**.
* Consumed by: `core/*`, `agents`, `orchestrators`, `cli`, `market`, and `inputs`.

## Test Strategy

* Validated indirectly across nearly all domain tests; direct coverage in `tests/unit/test_schemas_fetchpolicy_validation.py` and the media/listing test suites.
* Run:

  ```bash
  pytest -q --no-cov tests/unit tests/core
  ```

  `--no-cov` disables coverage for this subset run only; the project's ≥80% coverage gate
  (`pytest.ini`, `--cov-fail-under=80`) is enforced against the **full** `pytest` suite, not any
  one subset command.
